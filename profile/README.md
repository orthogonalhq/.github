Orthogonal builds local-first agent infrastructure for real people.

**NueOS** is a fully packaged Agent OS application for everyday people and families — helping them automate repetitive digital tasks, coordinate work across their apps and models, and get their time back while staying in control.

Under the hood, NueOS is a local-first personal AI control plane for model routing, memory, tools, workflows, and project-scoped automation.

> **Rename in progress:** Nous is becoming Nue/NueOS. The main repository remains `nous-core` during the transition.

```text
Cortex       Decision, reflection, governance, escalation
Memory       STM, LTM, distillation, retrieval, knowledge indexing
Subcortex    Model routing, tools, workflows, communication, witness chain
Autonomic    Storage, embeddings, health, configuration
```

Open source. Local-first. Built for user control.

**[nous-core](https://github.com/orthogonalhq/nous-core)** — the NueOS monorepo: desktop apps, web app, CLI, provider surface, memory packages, orchestration layers, and docs.

**[APM](https://github.com/orthogonalhq/apm)** — the Agent Package Manager: a registry and management tool for skills, workflows, and agent apps.
